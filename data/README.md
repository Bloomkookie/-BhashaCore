# BhashaCore Data Directory

This directory stores offline benchmarks, sample datasets, and preprocessed multilingual QA fixtures for BhashaCore.

## Contents
- `rag_sample.json`: Preprocessed public-service sample records conforming to the `KnowledgeEntry` schema (generated by `ingest_rag_suite.py`).
- Additional research subsets from AI4Bharat Indic-RAG-Suite can be staged here.
